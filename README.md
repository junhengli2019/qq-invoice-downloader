# 收票夹 · QQ / 163 邮箱发票下载网站

把邮箱中的发票 PDF 找出来，勾选后打包下载到电脑或手机。无需安装软件。支持 QQ（含 foxmail.com）和 163 邮箱；原 Windows 本地工具仍保留在 `发票下载工具/`。

## 使用网站

1. 选择 QQ 或 163，填写完整邮箱地址。
2. 在邮箱官方设置中开启 IMAP，生成客户端授权码并填入网站。**授权码不是邮箱登录密码，不要发到聊天或提交到 GitHub。**
3. 选择收件日期范围，阅读临时处理说明后开始查找。
4. 勾选要保存的 PDF，点击下载 ZIP。电脑浏览器通常保存到“下载”；手机可以通过浏览器下载列表或“文件”App 打开。具体保存位置由浏览器设置决定。
5. 下载完成后点击“清除本次数据”。无需真实邮箱即可通过示例模式体验全流程，示例 PDF 不可报销。

QQ 官方指引：https://help.mail.qq.com/detail/106/985 。QQ 设置路径通常为“账号与安全 → 安全设置 → 开启服务”。163 网页“设置 → POP3/SMTP/IMAP → 新增授权密码”；也可在网易邮箱大师“我 → 邮箱管理 → 第三方登录管理 → 通用授权码”生成。具体以官网当前页面为准。

## 支持范围

- 只读收件箱 INBOX，不发信、不删信、不改已读状态。
- 按邮件服务器的**收件日期**搜索，包含开始和结束当天；不等于发票开票日期。每次日期跨度最多一年。
- 主题、发件人或正文含“发票”/“invoice”才会进一步处理。结果是候选 PDF，不进行税务验真或金额识别，请自行确认。
- PDF 附件、直接返回 PDF 的正文链接，以及直接返回 ZIP 内的 PDF。
- 同一批按文件内容去重，同名但不同内容自动加后缀。
- 登录、验证码、过期和无法直接下载的链接，列在手动下载区。
- 暂不支持 OFD/XML、附件 ZIP、其他邮箱和全邮箱文件夹扫描。
- 最多处理最新 500 封邮件、100 个 PDF、总计 50 MB。单封邮件最多 20 MB，单个链接响应最多 10 MB，最多自动处理 30 条链接。达到限制会提示缩小范围。
- 每次扫描约 3 分钟上限（正在等待的网络操作可能延后结束），每 IP 每 10 分钟最多创建 8 次任务；每浏览器保留一批结果。

## 隐私

网站服务器会临时接收邮箱地址和授权码，并读取范围内邮件及附件。授权码只留在本次扫描的进程内存，不写入数据库、配置文件或应用日志。PDF 和邮件结果留在服务器内存，完成后 30 分钟到期；后台最多延后约 30 秒清理内存引用，过期立即无法下载。也可主动清除。

关闭网页不代表立即删除。运行中的取消任务会在下一个检查点停止并释放数据。服务重启、休眠或重新部署也会丢失全部任务。Python 内存对象释放不承诺物理内存覆写；基础设施运营商的系统日志策略独立于本应用。本项目不接入统计跟踪，不在浏览器持久存储授权码。

多浏览器会话隔离、跨站请求保护、请求体/任务数/并发限制、固定 IMAP 主机和 TLS 验证。正文下载拒绝内网/保留地址，解析后固定连接 IP 并校验 TLS 主机名，每次跳转重新校验。

## 本地运行网站

需要 Python 3.12 或更新版本。

```sh
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
flask --app webapp.app run --port 8765
```

打开 http://127.0.0.1:8765 。Windows 可使用 `.venv\Scripts\activate` 激活环境。线上版本通过 HTTPS 访问。

## Render 部署

服务类型 Web Service；Python；地区 Singapore；方案 Free。

- Build：`pip install -r requirements.txt`
- Start：`gunicorn webapp.app:app --bind 0.0.0.0:$PORT --workers 1 --threads 8 --timeout 240 --access-logfile /dev/null`
- 健康检查：`/healthz`
- 不需要配置任何邮箱授权码或数据库。
- 必须保持 **1 个 worker / 1 个实例**：任务仅在进程内存，多个进程会导致任务查不到。最多同时保留 3 批真实邮箱结果；另有独立的 3 批轻量示例容量，示例不会占用真实查找名额，也不会挤掉已有结果。同时扫描 2 个任务、下载流 1 个。

Render 免费服务在空闲后会休眠，再次打开可能等待约一分钟；免费额度和流量限制以 [Render 官方说明](https://render.com/docs/free) 为准。海外服务器连接国内邮箱可能触发安全提醒，请在邮箱官网确认。国内访问速度依当地网络而异。

## 验证

```sh
python -m unittest discover -s tests -v
```

测试覆盖模拟 QQ/163 只读连接、日期与容量限制、PDF/ZIP、重复文件、恶意链接、跨会话隔离、CSRF、清除和下载。模拟测试与示例下载不等于真实邮箱验证；真实邮箱须由用户在网站自行输入授权码完成。

## 目录

- `webapp/app.py`：网站 API、会话、任务和下载
- `webapp/mailbox.py`：QQ/163 只读邮件扫描和安全下载
- `webapp/static/`：中文响应式界面
- `tests/`：自动化测试
- `docs/website-design.md`：设计和验收边界
- `发票下载工具/`：保留的原 Windows 本地版（只使用 Python 标准库）

网站版使用 Flask 和 Gunicorn；“仅 Python 标准库”的说明只适用于原本地版本。
