第一次使用？

三步找到邮箱授权码

授权码是邮箱为第三方工具生成的专用密码。请在邮箱官方页面生成，不要把授权码发给他人。

  1. 1

    打开 QQ 邮箱网页版

    点击网页右上角头像，进入「设置 → 账号与安全 → 安全设置」。不同版本的入口名称可能略有差异。

  2. 2

    开启 IMAP / SMTP 服务

    找到 IMAP 服务并点击「开启服务」，按官方提示完成验证，可能需要 QQ 密码或手机 QQ 扫码。

  3. 3

    复制授权码，回到收票夹

    点击「生成授权码」，将生成的 16 位授权码填入本页「邮箱授权码」。Foxmail 地址也选择 QQ 邮箱。

前往 QQ 邮箱查看 QQ 邮箱官方教程 ↗
  1. 1

    打开 163 邮箱网页版

    登录后进入「设置」，选择「POP3 / SMTP / IMAP」或客户端设置。

  2. 2

    开启 IMAP / SMTP 服务

    按页面要求完成短信或手机验证，生成或新增「客户端授权密码」。

  3. 3

    复制授权码，粘贴到收票夹

    填写完整的 @163.com 邮箱地址。如果提示安全验证，请先回官方邮箱确认本次登录。

前往 163 邮箱
手机上找不到设置？

163 用户可在「网易邮箱大师 → 我 → 邮箱管理 → 选择邮箱 → 第三方登录管理 → 通用授权码」中获取。QQ 用户可尝试浏览器「请求桌面网站」，或先在电脑上生成授权码。

为什么连接失败，或没找到发票？

检查 IMAP 服务是否已开启、授权码是否有效，以及所选邮箱是否对应。邮箱安全策略可能拦截本次客户端登录，需要在官方邮箱确认。没有结果时，请扩大日期范围，检查发票邮件是否已移到其他文件夹。部分邮箱客户端设置只开放最近一段时间的邮件。

下载后，文件在哪里？

ZIP 通常保存在浏览器的「下载」列表或电脑「下载」文件夹。解压 ZIP 后即可查看 PDF。在线版的手机用户可从浏览器下载记录或「文件」App 查看；本机版地址不能直接在另一台手机打开。
数据处理说明

只为这一次，连接你的邮箱

查找发票时，邮箱地址和授权码会交给运行本网站的服务，用于连接 QQ 或 163。请确认运行位置，并只在信任的设备或网站使用。

程序会连接邮箱服务商；自动处理邮件中的发票链接时，也会访问对应的下载网站。不会向这些下载网站发送邮箱授权码。

授权码如何使用

授权码仅在本次任务的服务器内存中使用，不写入配置文件或应用日志；任务完成后不再保留。网页不会将授权码保存在本地存储中。授权码本身可能拥有更广泛的邮箱权限，请只在信任本网站时使用。

邮件与发票如何处理

程序只读查找收件箱，不发送、删除邮件或改变已读状态。PDF 和必要的邮件信息临时保留 30 分钟，也可点击「清除本次数据」。停止或重启服务会丢失这些临时结果；已下载到设备的文件不会被删除。

下载后由你保管

ZIP 文件通过浏览器保存到自己的设备。网页无法直接指定设备上的文件夹。请妥善保管下载文件；不再使用时，可到邮箱官方设置中撤销授权码。

适用范围

请只连接你有权使用的邮箱。程序寻找候选 PDF，不验证发票真伪，也不承诺识别所有发票。应用不主动记录授权码、邮件正文或发票内容；在线部署平台可能另行保留基础访问日志。
