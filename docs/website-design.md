# 收票夹网站设计

使用者无需安装 Python。电脑或手机浏览器选择 QQ / 163，填写邮箱客户端授权码与收件日期范围，勾选结果后下载 ZIP 到设备。

采用单一 Python Web 服务（Flask / Gunicorn），托管在 Render 新加坡免费实例。Sites 不支持 IMAP 所需的原始 TCP 连接，因此不适用。原 Windows 本地工具保留在原目录。

- 独立浏览器会话；所有任务、PDF 和授权码均不入数据库、不写磁盘。授权码仅存扫描调用栈，结束后解除引用。
- 只读 INBOX，按服务器收件日期检索。日期包含起止两天。每次扫描最近 500 封、最多 100 个 PDF、50 MB，运行时间与网络等待均有上限。
- 任务完成后 30 分钟过期；清除会终止任务并删除内存引用；关闭页面不等于即时清除；服务重启会丢失任务。
- 浏览器会话隔离、CSRF、同源检查、固定邮箱主机、网络地址限制、PDF 类型校验、资源上限。
- 支持 PDF 附件和可直达 PDF/ZIP 的链接；验证码、网页和登录链接给出人工处理入口。
- 示例模式使用显著标记的无效示例 PDF，用来验证筛选、勾选、打包与下载；不能替代真实邮箱验收。

验收覆盖 QQ/163 协议适配模拟、日期与只读行为、恶意附件/链接、会话隔离、错误状态、ZIP 内容、手机布局与公开部署健康检查。未经用户在页面自行输入邮箱授权码，不宣称真实邮箱端到端验证完成。
