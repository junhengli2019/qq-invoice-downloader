# 收票夹：在自己的电脑运行

## 第一次启动

1. 安装 [Python 3.12 或更新版本](https://www.python.org/downloads/)。Windows 安装时勾选 **Add Python to PATH**。
2. 把本项目完整解压到自己的文件夹，不要在压缩包里直接运行。
3. Mac 双击 **启动收票夹.command**；Windows 双击 **启动收票夹.bat**。首次询问是否安装依赖时，输入 `y` 并回车。
4. 启动窗口出现网址后，浏览器会自动打开 **http://127.0.0.1:8765**。没有自动打开时，复制这个地址到浏览器。

依赖只安装在项目的 `.venv-local` 文件夹，来自官方 PyPI；不会修改系统 Python，不安装开机后台服务。无需 Docker、数据库、网站口令或服务器账户。

Mac 如果双击不能启动，可打开终端，先进入项目目录，再运行 `bash 启动收票夹.command`。不要绕过系统安全警告；从可信来源重新获取项目，或请维护者检查。Linux 使用 `python3 run_local.py`。

## 使用只需三步

1. **先试示例**：不用邮箱，体验勾选、下载 ZIP、解压 PDF。
2. **连接自己的邮箱**：选择 QQ 或 163，填写邮箱与专用授权码。点页面里的“如何获取授权码”，不要填邮箱登录密码。
3. **查找并保存**：先选最近 7 天，找到结果后勾选需要的 PDF、下载 ZIP。下载后点“清除本次数据”。

收件日期不是开票日期。需要登录、验证码或已过期的网页链接可能需回原邮箱下载。找到的是候选 PDF，使用前请自行核对。

## 开始、停止与再次打开

- **开始**：每次双击启动器。保留启动窗口，浏览器只是操作界面。
- **停止**：回到启动窗口按 **Ctrl+C**。网页服务停止，临时结果清除；正在连接的邮箱会在下个检查点结束，可能需等待一次网络超时。
- **再次打开**：重新启动即可，关闭或重启期间的临时结果不会恢复。
- **只关闭网页不会停止服务**。电脑休眠或关机后也不能继续使用。

这个地址只能在**运行程序的这台电脑**打开。手机上的 `127.0.0.1` 指手机自己，并不是你的电脑。要让手机或外部用户访问，需要另行确定网络与 HTTPS 方案；本版本没有开启局域网、隧道、端口转发或防火墙规则。

## 常见问题

**提示端口 8765 被占用**：先检查之前的启动窗口是否还在。不要随意终止其他程序；也可以在项目目录运行 `python3 run_local.py --port 8766`，随后使用 http://127.0.0.1:8766 。Windows 把 `python3` 换成 `py -3`。

**首次下载依赖失败**：检查网络，运行 `python3 run_local.py --install` 重试。不要把邮箱密码或授权码填进终端，也不要关闭证书校验。

**重启后浏览器提示过期**：刷新页面，再开始一次新的查找。

**网站能打开，但连接邮箱失败**：去邮箱官网检查 IMAP 是否开启、授权码是否有效，以及是否需要确认安全提醒。此时不需要重新安装网站。

**电脑性能或内存占用**：本机版保留原来的容量限制：最多 3 批真实结果、2 个同时扫描、每批 PDF 50 MB；示例有独立的 3 批容量。只运行一个实例，不要同时开多个端口做大批量扫描。

## 数据在哪里

邮箱凭据从浏览器交给这台电脑上的服务，服务再连接邮箱；如邮件包含可下载链接，服务也会请求相应发票网站。没有把发票上传到收票夹云端。授权码不写入配置文件或应用日志；PDF 结果临时保存在进程内存，完成后 30 分钟到期，也可手动清除。

下载 ZIP 是用户主动保存到浏览器选定位置的文件。Python 释放内存不等于物理覆写；操作系统换页、崩溃转储和浏览器下载记录不由应用保证清除。请在自己的可信电脑使用。

## 给维护者的验证命令

```
python3 run_local.py --install
.venv-local/bin/python -m unittest discover -s tests -v
python3 run_local.py --no-browser
```

Windows 测试命令使用 `.venv-local\Scripts\python.exe`。本机入口固定监听 `127.0.0.1`，不接受 `--host`；不读取反向代理头，拒绝非回环 Host 或来源地址。官方服务组件：[Waitress](https://docs.pylonsproject.org/projects/waitress/en/stable/)。
