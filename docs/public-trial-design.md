# 票夹：QQ 邮箱发票在线试用

目标：普通用户无需安装，按「填写邮箱 → 选择日期 → 下载发票」完成操作。沿用现有收件箱发票处理逻辑，不发送、删除或标为已读，不接 AI，也不新增长期邮箱账号系统。

界面采用白色纸张与深绿色文件夹视觉。背景 #F3F6F4，正文 #183B30，主按钮 #176B53，辅助文字 #596B63，边线 #D6E1DA。标题用系统中文黑体，正文优先 PingFang SC / Microsoft YaHei，日期和数量使用等宽数字。真正的三步进度作为主要视觉元素，每屏只突出一个下一步按钮。手机单列、正文至少 16px、操作区至少 44px，允许减少动画。

授权指南在第一步就能打开：右上角头像 → 设置 → 账号与安全 → 安全设置 → 开启服务 → 生成授权码；注明旧版入口差异，链接到 QQ 官方帮助。邮箱密码只在 QQ 官方页面输入，本站只收授权码。生成前明确告知云端临时处理与文件保留期限并要求访客勾选同意。说明中不承诺授权码本身只有只读权限；本工具只进行读取。

一个 Python Web 服务部署在 Render 免费方案（工作区待用户选择）。Flask + Gunicorn 对外提供网页与接口，复用原有 Python 核心。单实例、单 Web 进程、最多两项并行任务；每项任务在可终止的独立子进程运行。授权码仅为该进程运行参数，不保存到文件、Cookie、日志或返回值。每位访客有随机 HttpOnly 会话 Cookie，所有状态与下载以该会话鉴权；更改操作同时校验同源和 CSRF。

任务独立临时目录，结果打包 ZIP；完成后 15 分钟到期，后台定时删除，也可主动停止并删除。重启清除临时数据并中断任务，页面提示重新开始。每次最多 31 天、300 封邮件、100 份 PDF、40 MB 总文件、有限正文链接及 3 分钟执行时间，超限不伪称全部完成。每小时次数、全站并发、保留文件总量均有限制。

公网上的下载链接逐跳解析并校验公开 IP，连接固定到已验证 IP，保留 TLS 主机名校验，拒绝内网、非 HTTP(S) 和非标准端口；邮件按尺寸有界读取，ZIP 展开同样限量。原本本机版仍可用。

示例入口明确标记为示例、不连接邮箱，下载内容也标为不可报销。测试覆盖模拟 IMAP 收信到 ZIP、隔离、伪造会话、跨站请求、超限、取消、清理、错误授权、手机布局及示例下载。部署后验证公开页面和 QQ TLS 连通性；没有用户在网页自行提供的有效授权码时，不声称已验证真实账号收信。

参考：QQ 官方 https://help.mail.qq.com/detail/106/985 （2026-10-31 核验）；Render https://render.com/docs/free 。免费服务闲置后可能启动较慢，不承诺持续可用或持久存储。
