遇到问题，先看这里

网站访问口令和邮箱授权码有什么区别？

网站访问口令是这个网站的门锁，请向部署者获取。邮箱授权码由 QQ 或 163 邮箱生成，只用于本次连接邮箱。两者都不要填成你的邮箱登录密码。

显示“认证被拒绝”，怎么办？

先检查所选邮箱与地址是否一致，再确认已在邮箱网页版开启 IMAP 服务。复制新生成的授权码，注意不要带空格。163 若提示客户端登录异常，请先到邮箱网页确认安全提示，再回来重试。

为什么没找到发票？

先扩大日期范围，或把关键词改成邮件主题里的商家名称。日期指邮件收件日期，不是开票日期。本版只扫描收件箱中的 PDF 附件；只有“查看发票”网页链接、OFD 或 ZIP 附件的邮件，需要回邮箱处理。邮件超过 300 封时，请缩小日期范围分批下载。

手机下载后，到哪里找文件？

先打开浏览器的“下载”列表，再在系统“文件”或“文件管理”中查找 ZIP 压缩包。点开压缩包解压，就能看到勾选的 PDF。下载后可点“清除本次临时文件”立即清理网站中的结果。
